# Hermes 3DS v1.0.0

Talk to your Hermes Agent from a Nintendo 3DS.

- Push to talk (hold A), spoken replies, live state screens, approvals on the 3DS
- Camera: press R, snap, ask about the photo
- Personas: switch with the D-pad, each with its own personality, voice and conversation
- Pip, a small floating TV robot, ships as the example persona with full art

## Files

- `hermes-3ds.cia`: install from the Home Menu with FBI
- `hermes-3ds.3dsx`: Homebrew Launcher, copy to `sd:/3ds/`
- `pip-sd-pack.zip`: optional, Pip's art. Unzip onto the root of the SD card

Setup: [docs/SETUP.md](SETUP.md). Needs the relay running on the computer next to Hermes.
